## Сборка и запуск

Из этой папки:

```bash
./build.sh
./run.sh
```

На текущем компьютере автоматически используются SDK и кеш библиотек из `../lab_01/.local/`. Исходники приложения, шейдеры и шрифт скопированы в `lab2`; исходники первой лабы не изменяются. Собственный каталог `.local/` имеет приоритет.

На другом Linux нужны C++20, CMake 3.20+, Git, Vulkan headers/loader, glslc, драйвер Vulkan и заголовки X11. Для Debian/Ubuntu:

```bash
sudo apt install build-essential cmake git libvulkan-dev glslc vulkan-validationlayers \
    libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libxfixes-dev libxrender-dev
./build.sh
./run.sh
```

При отсутствии прав администратора доступен `tools/setup-local.sh`, как в первой лабораторной; он требует настроенных apt-репозиториев, компилятора, CMake, Git, libX11-dev и Vulkan-драйвера. При первой конфигурации без кеша CMake скачивает GLFW 3.4, vk-bootstrap v1.4.321, VMA v3.4.0 и ImGui v1.92.9. В Wayland-сеансе нужен XWayland.

Для Windows нужны Visual Studio 2022 с C++, CMake, Git и Vulkan SDK:

```powershell
cmake -S . -B build-windows -G "Visual Studio 17 2022" -A x64
cmake --build build-windows --config Debug --parallel 4
.\build-windows\Debug\cg-lab-02.exe
```

Windows-конфигурация здесь не проверялась. Пути к шейдерам и шрифту задаёт CMake, поэтому рабочая директория запуска произвольная.

## Управление

Все параметры редактируются на панели ImGui:

- Камера: позиция XYZ, поворот вокруг Y, наклон, вертикальный угол обзора, ближняя/дальняя плоскости и скорость перемещения.
- Единственный направленный источник: направление хода лучей, цвет и интенсивность. Позиция для направленного источника не требуется.
- Фоновое освещение (ambient): цвет и интенсивность.
- Материал: альбедо, цвет блика и коэффициент блика (shininess).

Для управления мышью и клавиатурой поместите курсор в область сцены: ПКМ поворачивает камеру, WASD перемещает её вперёд/назад и в стороны, Q/E — вниз/вверх, Shift ускоряет движение. Колесо меняет угол обзора. Кнопки сброса восстанавливают камеру либо свет и материал. `Esc` закрывает окно.

## Освещение и данные

Во фрагментном шейдере вычисляются нормализованные мировые векторы `N`, `L`, `V` и полувектор `H = normalize(L + V)`. Направление `L` противоположно направлению хода лучей из интерфейса. Результат:

```text
ambientColor * ambientIntensity * albedo
+ lightColor * intensity * (albedo * max(dot(N, L), 0)
                           + specularColor * max(dot(N, H), 0)^shininess)
```

Блик учитывается только при `dot(N, L) > 0`. Нулевая интенсивность выключает направленный свет; нулевой цвет блика убирает зеркальную составляющую. Нулевое направление заменяется на `(0, -1, 0)`. Тор задан в мировых координатах, поэтому его модельная матрица единичная, а процедурные нормали уже находятся в мировом пространстве.

Один набор дескрипторов содержит один uniform buffer с матрицей view-projection, позицией камеры, параметрами направленного и фонового света и материалом. Буфер доступен вершинному и фрагментному шейдерам. Запись производится после ожидания fence предыдущего кадра; раскладка C++ проверяется на соответствие GLSL `std140`.

## Проверка

`build.sh` запускает тесты геометрии, нормалей, перспективной матрицы Vulkan, положения и движения камеры, независимости скорости от FPS, угла обзора и предельного наклона.

```bash
./tools/verify.sh
```

Для проверки отрисовки нужны Xvfb, xauth, Python с Pillow и Vulkan Validation Layers. Скрипт сохраняет восемь кадров, проверяет два ракурса, угол обзора, изменение размера окна, цвет источника, зеркальный блик и сумму ambient/diffuse/specular в линейном цветовом пространстве. Включена проверка синхронизации Vulkan. Результаты и снимки находятся в `checks/`. Проверка выполнена на Linux с Mesa llvmpipe.

Для воспроизводимого снимка можно выбрать ракурс и настройки освещения:

```bash
./run.sh --frames 35 --view side --capture /tmp/torus.ppm
./run.sh --frames 35 --preset specular --capture /tmp/specular.ppm
```

`--view`: `default`, `side`, `wide`. `--preset`: `default`, `ambient`, `diffuse`, `specular`, `red-light`, `matte`. Эти режимы изменяют параметры того же тора и единственного источника.

## Запуск первой лабораторной

```bash
cd lab_01
./build.sh
./run.sh
```

Требования к окружению и команды для Linux и Windows описаны в [README лабораторной](lab_01/README.md). При первой сборке CMake скачивает библиотеки; Vulkan SDK или локальные пакеты должны быть установлены заранее.

Следующие работы добавляются в папки `lab_02`, `lab_03` и далее. Файлы сборки и локальные зависимости исключены из Git; исходники, шейдеры, материалы задания, скриншоты и отчёты включены.
